## 四、三点须知

1. **范例文件里的机器绝对路径**（形如 `E:\…\cyrene-agent`、`D:\…\node24`）是**历史记录的原文**，
   描述当时那台机器的环境——当**举例**看，**不要照抄执行**。
   它们不影响可移植性：引用解析用的出处路径全部是**相对路径**。
2. **经验条目自身是完整的**（错误做法 / 症状 / 根因 / 正确做法 四段齐全）。
   即使不解开 `2-证据.zip`，经验库照样可用——出处只承担"溯源"与"唯一标识"两个作用。
3. **要迁移到你自己的项目**时：用规范 §1–§10 全部 + 通用经验库（H/M）全部 + 具体坑库**只取形状**。
   具体条目多为 Node / Electron / git 场景，**参考形状、别照抄结论**。
