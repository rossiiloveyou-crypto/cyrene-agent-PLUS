| 4. 看 `%APPDATA%\live2d-cyrene\transcripts\<hash>\transcript.jsonl` | 存在以渠道 sessionId 为键的轨迹目录，且含本轮条目 |
| 5. 渠道里问"我们刚才说了什么" | 她**记得**（渠道会话的 CTA 上下文连续） |

### C-3 · H-11 渠道审计可见性（5 步）

| 步骤 | 期望 |
|---|---|
| 1. 渠道里发一句**会让她失败**的消息（如临时把 Base URL 改错） | 渠道侧超时或错误回复 |
| 2. 聊天窗口 → 点侧栏「渠道控制台」按钮 | 出现控制台面板 |
| 3. 看「审计」列表并筛 `kind` | 有 **`turn_failed`（对话失败）** 条目，标题含 **`对话失败 · <发送者>`** |
| 4. 点开该条目 | 详情含三段：**用户原文** / 已生成未收尾的回复 / **失败原因** |
| 5. 设置里打开「记录成功轮次」后再正常聊一轮 | 出现 `turn_success` 条目，含**本轮调用过的工具** |

> **不算失败**：`recordTurnSuccess` **默认不记录**（`audit-events.ts:88`）→ 第 5 步必须先开开关。
> **本条失败的典型含义**：第 3 步只有 `tool_call`、**毫无 `turn_failed`** → 审计的"失败轮次"整段消失。

### C-4 · H-12 工具白名单 + 拦截关键词（6 步）

| 步骤 | 期望 |
|---|---|
| 1. 控制台 → 白名单与权限：建一个账号，**只勾「私聊」不勾「工具」** | 保存成功 |
| 2. 用该账号私聊让她做需要工具的任务（"现在几点？帮我查天气"） | 她**不调用工具**，只用文字回应或说明没权限 |
| 3. 同账号把「工具」勾上后重发同一句 | 这次**会调用工具** |
| 4. 控制台 → 关键词策略：加一条**拦截关键词**（如 `测试拦截`） | 保存成功 |
| 5. 渠道里发**含该词**的消息 | 消息**不进模型**；审计出现 **`message_blocked`** 条目（含被拦截用户与原内容 + 拦截理由） |
| 6. 发一条**不含**该词的消息 | 正常回复 |

> **失败的两个方向**：① 第 2 步照样调工具 → 白名单失效；② 第 5 步正常回复了 → 拦截关键词未接线。
