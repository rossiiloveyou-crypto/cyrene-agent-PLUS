# 渠道控制台

聊天窗口左侧按钮列里的 **控制台** 入口。它管两件事：

1. **谁可以和昔涟说话、谁能调用工具** —— 外部渠道（微信 / 飞书 / QQ / QQ 机器人）的「白名单与权限」；
2. **发生了什么** —— 每一次工具调用、每一条被拦截的消息、每一轮失败的对话，都实时记在这里。

## 一、白名单与权限

> 2026-09 更新：QQ（NapCat）设置页原来的「私聊 QQ 白名单」「放行群员 QQ 白名单」和「启用群员发言限制」
> 已全部迁到这里，改成按账号勾权限。
> 2026-10 更新：**群号白名单也移出了设置页**，改为「设置 → 记忆区块」——把群加进区块即视为加入白名单
> （旧配置里的 `allowedGroupIds` 仍兼容读取，不会被清空）。
> 群还没跟昔涟说过话时不会出现在「添加成员」列表里，用区块卡片上的「**手动加群**」按群号 / 群 openid 加入即可。

- 按 **渠道 + 账号** 添加，可附备注：QQ（NapCat）填 QQ 号；QQ 机器人（官方）填用户 openid；
  微信 / 飞书填对应平台的用户标识。
- 每个账号有三个权限，点条目上的 **权限** 按钮就地勾选，**打勾 = 放行，不勾 = 拦截**：

  | 权限 | 作用 | 受哪个总开关控制 |
  | --- | --- | --- |
  | 私聊 | 放行该账号的私聊消息 | 无（始终校验） |
  | 群聊 | 放行该账号在群里的消息（能叫动昔涟） | 群员发言限制 |
  | 工具 | 允许该账号真正调用工具（私聊、群聊同口径） | 工具调用拦截 |

- **新增账号默认只勾「群聊」**：想让它能私聊或能用工具，需要手动补勾。
- 名单里没有的账号，私聊和群聊都不会得到回复；工具调用也不会被执行。

### 两个总开关

| 开关 | 打开（默认） | 关闭 |
| --- | --- | --- |
| **群员发言限制** | 群聊里只有勾了「群聊」权限的账号能叫动昔涟，名单外的人 @ 也会被拦下并留痕 | 群聊不校验成员，群里任何人都能触发（此时「群聊」勾选暂时不生效） |
| **工具调用拦截** | 只有勾了「工具」权限的账号能真正调用工具 | 不拦截，任何账号都能调用工具 |

两个开关都是「总闸」：关掉之后对应的勾选不再参与判定，但名单与勾选本身保留，重新打开立即恢复。

> 「私聊 / 群聊」权限目前只对 QQ（NapCat）生效；其它渠道只使用「工具」权限。
> 改完立即生效，不需要重启渠道；名单为空且总开关打开时，私聊、群聊都不会响应。

### 与设置页全局「工具权限」的关系

设置 → 连接手机 →「工具权限」（`off` / `all`）是更上一层：`off` 时这一轮根本不把工具暴露给模型，
控制台里的「工具」权限也就无从触发；`all` 时才会在执行层按「工具」权限逐次判定。

### QQ 的准入顺序

私聊：**账号在名单里且勾了「私聊」** → 交给模型。

群聊：**是否在叫昔涟（@ 昔涟 / 命中触发关键词）→ 群聊是否已加入区块（= 白名单）→ 群员发言限制开启时校验该账号的「群聊」权限**
→ 拦截关键词 → 工具权限 → 进模型。

已加入区块的群里，没 @ 昔涟、也没命中触发关键词的消息会走**旁听**：写进本群的近期上下文，
让昔涟在被打断后仍能接上话题；不起模型调用、不写长期记忆、不进控制台。

群里没 @ 昔涟、也没命中触发关键词的消息只是群友闲聊，**不算请求**：直接丢弃，不写任何拦截记录
（否则没加白的群会把整群消息刷进控制台）。

## 二、控制台记录的四类事件

| 类型 | 什么时候产生 | 默认 |
| --- | --- | --- |
| **工具调用** | 渠道会话里每次工具调用（放行 / 失败 / 被权限拦截） | 总是记录 |
| **消息拦截** | 明确在叫昔涟（私聊 / 群里 @ 昔涟 / 命中「触发关键词」）但账号不在名单、或没勾对应权限；消息命中「拦截关键词」 | 总是记录 |
| **对话失败** | 这一轮对话没有成功收尾（超时、达到最大轮次、被取消、运行时错误、调用异常） | 总是记录 |
| **对话成功** | 正常完成的对话轮次 | **默认关闭**，可在列表上方开关打开 |

「记录全部对话（含成功）」默认关闭：开启后每次成功对话都会写一份日志，日志目录会增长得很快。

列表按时间倒序实时刷新，每条显示结果徽标（成功 / 失败 / 已拦截）、事件类型、标题、渠道 · 发送者 · 时间和摘要；顶部的筛选项可以只看 **已拦截** / **失败** / **成功**。

## 三、日志文件：完整内容不在界面上截断

所有记录的**完整内容**都写在独立日志文件夹里：

```
<userData>/channels/audit/
├── index.jsonl                     列表用的元数据（一行一条）
└── logs/
    └── 20260919-004512-tool_call-10001-ab12cd34.log
```

详情页只显示摘要，需要看全文时点 **打开日志文件**（用系统默认程序打开）或 **打开所在文件夹**。日志正文包含：

- 时间、类型、状态、渠道、群聊/私聊、会话 id、发送者、触发方式、耗时
- 失败 / 拦截原因
- **用户发送给昔涟的原文**（拦截与失败时保留，例如「被拦截用户 A：XXXXX」）
- 工具调用的完整参数与完整输出（不再截断）
- 错误堆栈

日志文件保留 30 天、最多 2000 份，超出的按时间从旧到新自动清理。「清空记录」会同时删除索引与全部日志文件。

## 四、拦截关键词与触发关键词

在 设置 → 偏好设置 里配置（见下节），渠道链路按固定顺序处理一条消息：

```
是不是在叫昔涟（私聊 / @ 昔涟 / 命中触发关键词）
   → 群聊是否已加入区块（= 白名单） → 群员发言限制（账号「群聊」权限） → 检测拦截关键词 → 工具权限 → 进模型
```

- **拦截关键词**：用户发给昔涟的消息里出现任一词块，直接拦截 —— 不回复、不进模型，只写一条「消息拦截」记录（含原文）。
- **触发关键词**：白名单群里出现任一词块时，**无需 @ 昔涟** 也会触发回复。只对通过全部准入校验的消息生效；模型会收到「本条命中触发关键词，按约定需要回复」的提示。

> 群里没 @ 昔涟、也没命中触发关键词的消息只是群友闲聊，**不算请求**：直接丢弃，不写任何拦截记录（否则没加白的群会把整群消息刷进控制台）。

## 五、被拦截之后会发生什么

- **工具被拦截**：不会中断对话。工具返回 `[拒绝] …`，模型据此知道这次操作没有被授权，可以自然地解释给用户，而不是假装执行成功。
- **消息被拦截**（叫了昔涟却不在名单 / 没勾对应权限 / 命中拦截关键词）：整条消息被丢弃，昔涟不会回复，控制台留下拦截记录。
