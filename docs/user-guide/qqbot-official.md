# QQ 机器人（官方开放平台）接入指南

Cyrene 支持通过 **QQ 官方机器人开放平台**（q.qq.com）以官方机器人身份接入 QQ。
与 [NapCat 渠道](./napcat-onebot.md) 互为补充：

| | 官方机器人（本渠道） | NapCat / OneBot 11 |
|---|---|---|
| 身份 | 机器人（消息列表里的"bot"） | 真实 QQ 号，是"好友" |
| 合规 | 官方协议，零封号风险 | 非官方协议，有封号风险 |
| 主动消息 | ❌ 不支持（官方 2025-04-21 起停用） | ✅ 随时可发 |
| 消息能力 | 被动回复：单聊 60 分钟内 4 条、群聊 5 分钟内 5 条 | 无限制 |
| 群聊 | 仅响应白名单群中的 @（或群主开启全量后接收全部消息） | 同左 |
| 收发媒体 | 收图片/语音/视频/文件；发仅文本 | 全媒体收发 |

## 一、创建机器人

1. 访问 [QQ 开放平台](https://q.qq.com/)，用 QQ 号登录
2. 「创建机器人」→ 填写名称/简介/头像
3. 进入「开发设置」页面，记下 **AppID** 和 **AppSecret**（Secret 只显示一次，丢失需重置）
4. **沙箱模式**：新机器人默认沙箱，只有「沙箱配置」里添加的测试用户能给它发消息。上线需提交审核

## 二、在 Cyrene 中配置

设置窗口 → 外部渠道 → **QQ 机器人（官方开放平台）** 卡片：

1. 填入 AppID / AppSecret → 点「保存并连接」
2. Secret 使用系统钥匙串加密落盘（safeStorage），保存后不再回显
3. 状态显示「网关已连接」即成功

### 白名单（openid 模型）

官方平台用 **openid** 标识用户和群（不是 QQ 号），且用户事先不知道自己的 openid。因此：

- **放行所有单聊**：开关打开后所有私聊放行（适合个人机器人）
- **单聊用户 openid 白名单**：默认模式。不知道 openid 时，先用 QQ 给机器人发一条消息，
  Cyrene 会在卡片反馈区显示「最近被拒的 openid」，复制进白名单即可放行
- **群 openid 白名单**：群聊必须加白（群内还需 @ 机器人）。白名单已并入「设置 → 记忆区块」：
  在区块卡片上点「**手动加群**」→ 选 `QQ 官方机器人` → 填群 openid，加进区块即视为加入白名单。
  获取 openid 的方式同上——在群里 @ 机器人发一条消息，反馈区会显示群 openid（复制后填进「手动加群」即可；
  群从没 @ 过机器人时，也只能用这个入口加白）

## 三、被动回复限制

官方已停止主动推送，Cyrene 的所有回复都是**被动回复**（引用触发消息发送）：

- 单聊：收到消息后 60 分钟内可回复 4 条
- 群聊：收到消息后 5 分钟内可回复 5 条
- 超窗/超次后该条消息无法再回复，需用户重新发消息触发
- 长回复会被 Cyrene 自动分段，但受上述条数上限约束（超限部分丢弃并记录日志）

**主动对话/主动投递功能不适用于本渠道**（官方无主动消息能力）。需要 Cyrene 主动找你聊天请使用 NapCat 渠道。

## 四、其他说明

- **URL 限制**：QQ 平台不允许消息中包含外部链接，Cyrene 的回复若带 URL 可能发送失败
- **群聊工具策略**：与 NapCat 渠道一致——群聊不再强制纯 Chat，是否暴露工具跟随全局「工具权限」开关；谁能真正调用工具由聊天窗口「控制台 → 白名单与权限」里该账号的「工具」权限决定（「工具调用拦截」默认打开，未授权的调用会被拒绝并记录），群聊仍共享个人记忆。详见 [渠道控制台](channel-console.md)
- **群聊触发**：官方平台只推送 @ 机器人的群消息，因此「触发关键词」（设置 → 偏好设置）在官方机器人渠道不适用，仅对 NapCat 渠道生效。
- **拦截记录**：单聊用户、以及群里 @ 了机器人的消息，若不在白名单（或所在渠道条目没勾对应权限）会被丢弃，并在渠道控制台留下一条带原文的拦截记录；群主开启「群全量」后推来的普通群消息只是群友闲聊，不算请求，同样被丢弃但不写拦截记录。
- **出站媒体**：当前版本仅支持发文本（官方富媒体需分片上传，后续版本支持）；
  入站图片/语音/视频/文件可正常接收并下载（8 MiB 上限）
- **频控**：受全局「每用户每分钟消息数」限制（默认 10）
